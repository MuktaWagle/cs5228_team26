# AI usage

We used GPT Luna 5.6 Medium as an AI-assisted coding and research tool during this project.

AI assistance was used to help drafting code, identify suitable Python libraries, modules, classes, and functions, and troubleshoot implementation issues. It was also used to help structure the documentation.

AI-generated code was treated as working drafts, not as authoritative results. We inspected, adapted, and tested the code in the context of our dataset and project requirements. We decided the methods of data preparation, validation, feature handling, and different kinds of modeling independent of AI.
